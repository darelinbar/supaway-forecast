# SUPAWAY · תחזית חתירה למחר

דף אחד שמסכם פעמיים ביום את התחזית של מחר לחוף מכמורת (תחזית בית ינאי), למועדון SUPAWAY.

- **גלים:** GoSurf
- **רוח:** Windguru (נקודת Beit Yannai) בלבד
- Surfline הוצא כי הוא חוסם שליפה אוטומטית.
- **גיבוי:** אם מקור לא עונה, הנתון החסר מגיע מ־Open‑Meteo, והדף מסמן את זה.

## איך זה עובד
- `scripts/fetch.mjs` שולף את הנתונים ושומר אותם ב־`docs/data.json`.
- `.github/workflows/update-forecast.yml` מריץ את השליפה כל יום בסביבות 11:00, 17:00 ו־19:00 (שעון ישראל, גם בשעון קיץ) ושומר את התוצאה.
- `docs/index.html` הוא הדף עצמו. GitHub Pages מגיש אותו מתיקיית `docs`.

## ספים
- **מעולה:** רוח עד 5 קשרים וגלים עד 50 ס"מ.
- **מבטלים:** רוח מעל 12 קשרים או גלים מעל 70 ס"מ.
- **סשן ראשון:** מתחיל 07:00 או 07:30. **סשן שני:** מתחיל בין 08:00 ל־10:00. **שקיעה:** השעה שלפני השקיעה.

## הרצה ידנית
בלשונית **Actions** → **Update forecast** → **Run workflow**.
